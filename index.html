Frequently Asked Questions

What is Morse code? +
Morse code is a communication system that encodes text characters as sequences of dots (.) and dashes (-). Developed in the 1830s by Samuel Morse, it was the foundation of global telegraph communication and is still used today by ham radio operators and in emergency signaling.
How do I use this Morse code translator? +
Simply type your text in the input box above and the Morse code appears instantly in real time. For audio playback, image decoding, and file conversion, visit our full tool at morse-codetranslator.net.
What does SOS mean in Morse code? +
SOS in Morse code is: · · · — — — · · · (three dots, three dashes, three dots). It is the international distress signal. It was chosen because it is easy to transmit and recognize, not because it stands for any specific phrase.
