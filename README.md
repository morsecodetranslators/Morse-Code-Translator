## 📡 About Morse Code

Morse code is a method of encoding text using dots (.) and dashes (-).
Originally used in telegraphs, now used in aviation & emergency signals.

**Example:**
- Hello = .... . .-.. .-.. ---
- SOS = ... --- ...
